# 04_Tests: Session Validation

This directory contains the logic for **verifying and validating** the success of our prototypes.

## 1. Directory Structure
- `[Name].test.tsx` — Integration or end-to-end tests for specific prototype missions.
- `setup.ts` — Global testing configuration.

## 2. Validation Mandate
All testing sessions here should generate data that flows into `05_analytics` to provide a complete feedback loop.
