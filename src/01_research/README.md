# Research Section

This section centralizes all research, analytics, and user-centric documentation for the project.

## Structure
- `test-documentation/` — Test plans, results, methodologies
- `demographics/` — User demographics, analytics summaries
- `personas/` — User personas, journey maps, empathy maps
- `analytics/` — Analytics data and reports
- `database/` — Static research database (React/MVVM)

## Usage
- Reference this section for all planning, design, and decision-making.
- Data in subfolders is used by agents and designers to inform features and prototypes.
