# .agent Directory

Meta-rules and architecture definitions for the Sleipnir workspace — the
short-form reference agents should read before touching code. For the full
technical architecture, see the root [`ARCHITECTURE.md`](../ARCHITECTURE.md);
for setup and commands, see the root [`README.md`](../README.md).

- `RULES.md` — The foundational AI operating mandates (roadmap-first,
  the 00–05 pipeline, MVVM conventions, and rules specific to Sleipnir's own
  built-in chat agent).
- `Architecture.md` — Short directory map and key boundaries.
- `index.json` — Index of planning/roadmap documents (currently empty; see
  `src/00_planning/roadmaps/` for the actual roadmap files).
